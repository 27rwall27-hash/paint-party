Custom Audio (optional)

Use your own audio for music/announcer instead of the built-in defaults: paste a YouTube link, or upload a .wav (or other audio) file — an uploaded file always takes priority over a YouTube link for that same slot. Leave everything blank to keep the default. Changes apply from the next round. Volume sliders apply live and affect whichever source is active (uploaded file, YouTube, or the built-in default).

Play Online (beta)

Create a room and share the 4-letter code with friends, or enter a code someone shared with you. Everyone online plays with WASD to move and Space to paint, regardless of which slot they're assigned.
